# V6 External Trust Verifier

Public, non-production trust-verification workspace.

This repository is intentionally limited to privacy-safe trust metadata, reviewed verifier code,
dependency manifests, and Sigstore/drand verification artifacts. It must not contain the V6
production repository, raw Windows evidence, secrets, buyer/customer information, or commerce payloads.

Current state: setup candidate only. No Native gate or Phase-A gate is promoted by the repository itself.
